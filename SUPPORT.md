# Support

Start with the [documentation site](https://nix-forge.github.io/nix-conf/) and
the [starter configuration](docs/guide/first-configuration.md). The guide
separates reusable features from the deployed Linux and macOS examples.

For a bug or a reproducible configuration problem, [open an issue](https://github.com/nix-forge/nix-conf/issues/new).
Include the commit or input revision, target system, relevant module options,
the command that failed, and the smallest useful log excerpt. Remove secrets,
private host details, and personal paths before posting.

Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose
security-sensitive details in a public issue.

This project does not provide managed system administration or support for
private deployments. Public, minimal reproductions are the best way to get help
and improve the guide for the next user.
