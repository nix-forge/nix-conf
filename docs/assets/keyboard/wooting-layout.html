Four positions change

Left Win → Option
Left Alt → Command
Right Alt → Command
Right Ctrl → Option
Keep left Control and Fn in place.

One set of shortcut roles

Command · application actions
Control · terminal commands
Control + Option · window/workspace actions
Fn · navigation, media and lighting

This is a keycap and mapping guide, not an RGB preview. The export preserves typing actuation, lighting, Caps Lock and the existing Fn layer. Right Control is replaced by Option; left Control remains available. Firmware Fn is not Apple's Globe key. Use the Mac Work export on both operating systems; do not apply another modifier swap in software.
